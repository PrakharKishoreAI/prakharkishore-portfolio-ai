MAJOR ACADEMIC PROJECT
==============================

Title:
Brain Tumor Detection Using Deep Learning and Explainable AI

Description:
Prakhar's major academic project focuses on brain tumor detection and classification using Deep Learning and Explainable AI (XAI).

The project uses a Vision Transformer (ViT) model to classify brain MRI images into four classes:
1. Glioma
2. Meningioma
3. Pituitary Tumor
4. No Tumor

Model:
Vision Transformer (ViT-B/16)

Dataset:
Brain MRI image dataset containing 7,200 images.

Training Images:
5,040

Testing Images:
2,160

Techniques:
- Deep Learning
- Computer Vision
- Vision Transformer (ViT)
- Transfer Learning
- Image Augmentation
- Explainable AI (XAI)
- Grad-CAM
- LIME

97.36%

K-Fold Cross-Validation:
5-Fold Cross-Validation

Reported K-Fold Accuracy:
98.51%
