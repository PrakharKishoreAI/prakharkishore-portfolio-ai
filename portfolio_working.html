Prakhar's major academic project is titled "Brain Tumor Detection Using Deep Learning and Explainable AI". It focuses on brain tumor detection and classification using a Vision Transformer (ViT) model to classify brain MRI images into four classes: Glioma, Meningioma, Pituitary Tumor, and No Tumor. The project reported a test accuracy of 97.36% and a 5-Fold Cross-Validation accuracy of 98.51%.
